n8n vs Node-RED — pricing & features compared

n8n vs Node-RED
Both are open-source, self-hosted and free software, so our figures put them at the same cost — your server (see the table). They serve different builders: n8n is a general-purpose automation tool with 1,868 app integrations, AI/LLM nodes and a visual editor aimed at business workflows, while Node-RED (Apache 2.0) is event-driven and excels at IoT/hardware, wired in a flow editor with Node.js function nodes. Pick n8n for SaaS automation, Node-RED for devices and events. See the price table below for figures.
